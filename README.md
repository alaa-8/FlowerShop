# Flower Market | Boutique Florist & Fine Sweets

A boutique e-commerce web application for an artisanal flower and confectionery boutique based in Amman, Jordan.

## 🌸 Features

- **Hero & Storytelling Showcase:** Elegant editorial layout with luxury fonts and floating botanical accents.
- **Interactive DIY Bouquet Studio:** Live visualizer allowing customers to customize flowers, wrapping tones, and sweet gift add-ons with automatic price recalculation.
- **Filterable Product Catalog:** Instant categorization across Fresh Flowers, Fine Sweets, and Curated Gifts.
- **Dynamic Slide-out Cart Drawer:** Real-time quantity counter, subtotal calculations, dynamic free-delivery progress indicator ($50 threshold), and local storage persistence.
- **Interactive Floral Gallery:** Responsive image grid with full-screen lightbox modal.
- **Inquiry & Contact Concierge:** Direct customer contact form with interactive feedback toasts.
- **Fully Responsive:** Optimized for desktop, tablet, and mobile with dedicated mobile menu navigation.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or host the repository directly using **GitHub Pages**:

1. Clone or download this repository.
2. Push to your GitHub account.
3. In repository **Settings** > **Pages**, choose the `main` branch as the source.
4. Your website will be live instantly!
